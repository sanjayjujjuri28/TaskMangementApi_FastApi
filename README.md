# Task Management API

A task management application built while learning FastAPI, PostgreSQL, SQLAlchemy, and frontend-backend integration.

## Features

- Create tasks
- View all tasks
- View a single task
- Update tasks
- Delete tasks
- Mark tasks as completed
- PostgreSQL database
- SQLAlchemy ORM
- Pydantic validation
- FastAPI REST API
- HTML/CSS/JavaScript frontend
- Edit and delete tasks from the UI

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Psycopg
- Pydantic
- HTML
- CSS
- JavaScript
