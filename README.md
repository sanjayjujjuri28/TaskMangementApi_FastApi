# Task Management API

A full-stack task management application built with **FastAPI, PostgreSQL, SQLAlchemy, and JavaScript**.

This project was built to understand how a real backend application works from request to database and back to the frontend.

## 🚀 Features

- Create tasks
- View all tasks
- View a single task
- Update tasks
- Delete tasks
- Mark tasks as completed
- PostgreSQL database
- SQLAlchemy ORM
- Pydantic validation
- FastAPI REST API
- HTML/CSS/JavaScript frontend
- Frontend connected directly to FastAPI
- Persistent database storage

## 🛠️ Tech Stack

### Backend

- Python
- FastAPI

- PostgreSQL

### Frontend
